# 세 번째 단계의 소량 수집 목록

이 목록은 여러 CVE를 차례로 받는 기능을 확인하기 위한 실제 공개 기록 3건임. 대상 프로그램이나 공격 코드를 실행하지 않음. 프로그램 보호 대상이나 실제 위험 판정을 확정한 목록은 아님.

선정 근거: [Node.js 공식 보안 공지](https://nodejs.org/en/blog/vulnerability/december-2025-security-releases).

2026-09-17 준비 시 공식 API의 세 기록 모두 요청 번호와 일치했으며 dataVersion 5.2·PUBLISHED였음. 자료는 나중에 갱신될 수 있으므로 실제 수집 결과의 시각·확인값·상태를 확인함.

현재 정리 기능은 5.2만 지원함. 실제 재조회한 자료가 다른 형식이면 UNSUPPORTED_FORMAT 등 해당 상태로 남기며 파일을 임의로 고치지 않음.

CVE 자료 이용 조건은 https://www.cve.org/legal/termsofuse 에서 확인함. 실제 원본·정리 결과와 함께 기존 CVE_LICENSE_NOTICE.txt를 보존함. 이 목록에 번호가 있다는 사실은 관련 프로그램이나 재현 코드의 배포 허락을 대신하지 않음.
