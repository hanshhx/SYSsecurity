# v0.4.0 수집기 사용법

수집기는 취약점 정보를 가져오고 읽기 쉬운 구조로 저장함. 파일 형식 검사는 자료의 구조를 확인하는 것이며 취약점이 사실인지 재검증하거나 현재 프로그램의 실행을 막는 기능이 아님.

## 무엇으로 조회할 수 있나

| 알고 있는 것 | 실행할 파일 |
|---|---|
| CVE 번호 하나 | `fetch_cve.py`로 원본 수집 후 `normalize_cve.py`로 정리 |
| CVE 번호 목록 | `batch_cves.py`가 수집·정리를 순서대로 연결 |
| npm 이름·정확한 버전 | `query_osv.py`로 OSV 관련 기록 조회·정리 |

프로젝트 최상위 폴더에서 실행함. 필요한 Python 패키지는 기존 `.venv`에 설치함. 처음 설치하는 경우 [프로젝트 안내](../README.md)를 참고함.

```bash
# CVE 번호 목록: 원본 수집과 정리를 함께 수행함
.venv/bin/python collector/batch_cves.py --list collector/examples/cve-step3-small.txt

# npm 이름과 정확한 버전으로 조회함
.venv/bin/python collector/query_osv.py --package tar --version 6.1.0

# 원본만 한 건 받는 경우
.venv/bin/python collector/fetch_cve.py CVE-2025-55130
```

원본만 받은 경우 출력된 수집 폴더 경로를 다음 명령에 넣어 정리함. 아래의 `수집폴더` 부분은 실제 출력 경로로 바꿔야 함.

```bash
.venv/bin/python collector/normalize_cve.py "수집폴더"
```

## 지원 범위와 결과

- CVE 기록 5.1에는 공식 규칙 5.1.1, 기록 5.2에는 규칙 5.2.0을 적용함. 원본 버전을 바꾸지 않음.
- CVE 5.0은 원본 수집만 가능하며 정리는 미지원으로 남김. 모르는 형식은 임의로 해석하지 않음.
- OSV 기록은 1.0.x~1.9.x를 확인함. 처음 지원하는 조회 대상은 npm임.
- CVE 목록은 중복을 한 번만 처리함. 한 건 실패 후 나머지는 처리하지만 전체를 완전한 성공으로 표시하지 않음.
- OSV는 다음 페이지까지 받아야 완료임. 오류·지원하지 않는 응답을 조회 결과 0건으로 바꾸지 않음.
- 정상 기록, 철회, 정보 누락, 미지원 형식, 통신·저장 실패를 구분함. 점수 없음은 0점이 아님.
- `readyForMatching=false`는 설치된 프로그램과의 비교가 아직 연결되지 않았다는 뜻임.

최종 목록 결과는 `reports/cve-batches/.../batch.json`, OSV 조회 결과는 `reports/osv/.../result.json`에 있음. 각 결과가 안내하는 원본·출처 경로를 함께 보관함. 반복 실행하면 새 폴더가 생기며 이전 결과는 보존함.

OSV 정리 결과의 `records[].data`는 받은 원문 항목을 보존함. `matchingPackageIndexes`는 이름·생태계가 같은 원문 항목 위치이며 버전 영향 여부의 자체 판정이 아님. 위험 평가 문자열을 그대로 보존하고 아직 숫자 점수로 재계산하지 않음.

## 처리 제한과 이용 조건

CVE 목록은 중복 제외 1,000개까지, 기본 건별 시간 제한 45초·건 사이 대기 1초임. OSV는 한 페이지 2 MiB, 전체 원본 20 MiB, 100페이지, 고유 기록 10,000개, 수집 작업 180초가 초기 제한임. OSV 수집 후 부모가 수행하는 원본 재대조 시간은 별도임. 제한에 도달하면 일부 결과를 전체 완료로 표시하지 않음. 자동 재시도·중단 지점 이어받기는 이번 범위가 아님.

조회 한도는 최종 보호 사례 목표와 다른 숫자임. 지금 1,000개의 취약점에 대한 보호 기능을 구현했다는 뜻이 아님.

CVE와 GHSA의 이용 고지는 원본 및 정리 자료와 함께 보관함. 모든 OSV 자료가 같은 조건은 아니므로 미확인 출처는 `LICENSE_REVIEW_REQUIRED`로 남김. 재배포 전에 해당 출처의 조건을 확인함. 실제 수집 결과와 개인 일지는 GitHub에 올리지 않음. 시험에 필요한 소량 고정 자료는 출처·이용 조건과 함께 `fixtures/`에 제공함.
